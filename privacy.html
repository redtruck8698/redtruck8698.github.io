Privacy Policy — shorts-agent

Last updated: November 12, 2026 · Home

1. Who this applies to

shorts-agent is a personal tool used only by the owner of one YouTube channel. It does not collect information from viewers or from any other people.

2. What data the tool accesses

With the channel owner's permission (Google OAuth), the tool uses YouTube API Services to:

  • upload videos to the owner's channel (scope: youtube.upload);
  • read the owner's channel and video information (scope: youtube.readonly);
  • read the owner's channel analytics, such as views, likes and watch time (scope: yt-analytics.readonly).

It does not access email, contacts, payment information, or any other Google data.

3. How the data is used and stored

  • Analytics numbers are used only to decide how to improve the owner's next videos, and are stored as files in the owner's private storage.
  • The OAuth access token is stored only in the owner's private environment and is never shared or published.
  • No data is sold, shared with third parties, or used for advertising.

4. How to revoke access

The owner can remove the tool's access at any time at Google Account › Third-party access. Stored analytics files can be deleted by the owner at any time.

5. YouTube and Google policies

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

6. Contact

Questions: open an issue on GitHub.
