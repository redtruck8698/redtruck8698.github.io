shorts-agent

A personal tool for one YouTube channel owner to publish Korean-language science Shorts.
한 채널 운영자가 자기 채널에 한국어 과학 쇼츠를 올리기 위한 개인용 도구입니다.

What it does

  • Edits openly licensed science videos (public-domain NASA footage and Creative Commons videos) into vertical Shorts with Korean narration and subtitles, always crediting the original creator and license.
  • Uploads those Shorts to the owner's own YouTube channel through the YouTube Data API, only after the owner approves each one.
  • Reads the channel's own analytics (views, likes, watch time) through the YouTube Analytics API so the owner can improve future videos.

Who uses it

Only the owner of the channel. It is not offered to other users, and no one else signs in to it.

하는 일

  • 공공 저작물(NASA)과 크리에이티브 커먼즈 과학 영상을 세로 쇼츠로 편집하고 한국어 해설과 자막을 넣습니다. 원작자와 라이선스는 항상 설명란에 밝힙니다.
  • 채널 주인이 승인한 영상만 YouTube Data API 로 자기 채널에 올립니다.
  • 다음 영상을 개선하려고 자기 채널의 분석 지표(조회수, 좋아요, 시청 시간)를 YouTube Analytics API 로 읽습니다.
